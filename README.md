# 株活ファイター ラタヒ

株活ヒロイン「ラタヒ」が戦う、ブラウザで遊べる3D対戦アクションです。写真から起こした3Dモデルに Blender でリグを入れ、three.js で動かしています。ビルド不要、HTML 1枚とモデル1つだけで動きます。

**▶ 遊ぶ: https://t-hirata-netizen.github.io/ratahi-fighter/**

パソコンはキーボード、スマートフォンは画面下のボタンで操作します。3ストック先取でCPUの「ベアード」と戦います。

## 操作

| キー | 動作 |
|---|---|
| `A` `D` | 左右に移動 |
| `W` | ジャンプ（空中でもう一度押すと2段ジャンプ） |
| `S` | しゃがむ・急降下・すり抜け床を降りる |
| `J` | 通常攻撃（長押しして離すとスマッシュ） |
| `K` | 必殺技 |
| `L` | ガード |

方向キーとの同時押しで技が変わります。スマートフォンでは自動で画面ボタンに切り替わります。

## 技

ラタヒの技は株式投資の用語から名前を取っています。

| 種別 | 技名 | 入力 | ダメージ |
|---|---|---|---|
| 弱攻撃 | デイトレ | `J` | 2.5 → 3.2 |
| 横強 | 板寄せ | `←→` + `J` | 8 |
| 上強 | 上方修正 | `W` + `J` | 7 |
| 下強 | 押し目 | `S` + `J` | 6 |
| 横スマッシュ | 暴落 | `J` 長押し | 16 |
| 空中N | スキャルピング | 空中 `J` | 7 |
| 空中前 | 利確 | 空中 `←→` + `J` | 10 |
| 空中上 | 増配 | 空中 `W` + `J` | 8 |
| 空中下 | ナイアガラ（メテオ） | 空中 `S` + `J` | 12 |
| 通常必殺 | 指値注文 | `K` | 6 |
| 横必殺 | ナンピン買い | `←→` + `K` | 11 |
| 上必殺 | ストップ高 | `W` + `K` | 9 |
| 下必殺 | 損切り（カウンター） | `S` + `K` | 反撃 |

ダメージ%が高いほど遠くへ吹き飛びます。場外に出されると1ストック失います。

## 作り方

1. **モデル生成** — キャラクターデザインから Tripo Studio と Hitem3D で3Dメッシュを生成。出力は200万ポリゴンのOBJでボーンなし
2. **軽量化** — Blender で6万ポリゴンに削減、身長1.5mに正規化、8192pxのテクスチャを2048pxへ
3. **リグ** — 22ボーンのアーマチュアを組んで自動ウェイトでスキニング。スカートは腰ボーンに固定し、左手とスカート裾が融合していた205面を切除
4. **書き出し** — glTF Binary（2.4MB）
5. **ゲーム** — three.js でボーンを毎フレーム直接回してポーズを作成。アニメーションクリップは使わず、ポーズ辞書を補間しています

## 技術

- [three.js](https://threejs.org/) 0.147.0（CDNから読み込み）
- 依存パッケージなし、ビルドステップなし
- モデルは glTF Binary、22ボーンのスキンメッシュ

ローカルで動かす場合は、ファイルを直接開かずに簡易サーバー越しに開いてください。モデルの読み込みに fetch を使うためです。

```bash
python3 -m http.server 8000
```
